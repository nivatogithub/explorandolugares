# Control visual añadido durante Jardín

- Revisar también fondos pequeños: el modelo puede inventar una iglesia aunque la actividad sea café, aves o caminata. Si no se verificó ese hito, excluir explícitamente torres, cúpulas y monumentos en el encargo; retirarlos mediante edición y revisar de nuevo.
- No confundir la basílica pétrea neogótica de Jardín con un templo colonial de fachada amarilla o blanca con dos campanarios. No emplear una iglesia genérica para representar el pueblo.
- Garrucha artesanal no equivale a góndola moderna. Evitar cañones exagerados, palmeras o urbanismo no documentado en el fondo.
- Mantener especies: gallito de las rocas andino y loro orejiamarillo tienen morfologías y hábitats diferentes.
- Una composición independiente conserva fuentes factuales y se declara ilustración; no se presenta como copia exacta de una calle, patio, ruta o distribución de mobiliario.

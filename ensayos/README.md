# Ensayos de Explorando Lugares

Cada propuesta nueva va en su propia carpeta, con un `index.html` y un documento que indique fecha, objetivo, estado, cambios, recursos/licencias y pendientes. Usar rutas relativas para poder comprobar después la compatibilidad con alojamiento estático.

Estado actual: **propuesta visual v1 pendiente de aprobación**. La entrada abre `v1/index.html`. Las decisiones y límites se documentan en `v1/DECISIONES.md`. El borrador v0.1 sigue intacto en `design/pasaporte-local/`; la propuesta nueva no utiliza estilos ni contactos de Paradigma Solutions.

Mantener alternativas numeradas y visibles cuando se comparen. Diferenciar contenido en preparación de información verificada. No colocar secretos, datos privados o contactos de prueba reales aquí: todo lo versionado y servido debe ser apto para revisión.

Esta carpeta no se publica automáticamente. No sustituye `public/` ni `design/pasaporte-local/`. La aprobación de una propuesta y su publicación son decisiones independientes y explícitas.

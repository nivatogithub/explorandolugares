# Nuevas propuestas: portal general y páginas de destino

Sustituyen la exploración anterior para la elección de diseño. public/ no cambia hasta elegir.

Abre index.html para ver las cinco propuestas y comparar ambas vistas. Cada propuesta permite entrar a Jericó, volver al portal y navegar Hoteles, Restaurantes, Comercios, Experiencias y Transporte. Son prototipos de diseño: no publican negocios, reservan ni envían datos.

El inicio presenta Explorando Lugares como marca general y muestra Jericó únicamente como entrada del listado de destinos. La fotografía local aparece solo dentro de la página del pueblo. No se incluyen otros destinos ficticiamente disponibles.

Direcciones: Portal azul (directorio claro), Vibrante (marca expresiva), Horizonte (contraste oscuro y tipográfico), Editorial (guía con serif), Comunidad local (viajeros y negocios).

# Kit inicial de identidad — Explorando Lugares

Este material está listo para uso manual en canales sociales. Mantiene la identidad actual: crema cálido, dorado, naranja y verde petróleo. No reemplaza los activos del sitio web.

## Archivos

| Archivo | Uso |
|---|---|
| `logo/explorando-lugares-logo-transparente-2048.png` | Logo maestro para piezas, aliados y presentaciones. No agregar fondo ni estirar. |
| `perfil/perfil-instagram-whatsapp-1080.png` | Foto de perfil para Instagram y WhatsApp Business. |
| `whatsapp/portada-catalogo-y-bienvenida-1200x628.png` | Imagen de bienvenida o portada informativa de WhatsApp Business. |
| `instagram/00-presentacion-1080.png` | Primera publicación: presentación del portal. |
| `instagram/01-destinos-1080.png` | Publicación sobre destinos y planeación. |
| `instagram/02-ideas-para-viajar-1080.png` | Publicación dirigida a viajeros. |
| `instagram/03-negocios-locales-1080.png` | Invitación para negocios locales; usar cuando se quiera captar registros. |
| `instagram/04-historia-1080x1920.png` | Historia vertical para enlazar al portal. |

## Regla visual mínima

Usar el logo con aire alrededor. En piezas nuevas, priorizar fondo crema (`#FFF9F0`), naranja (`#E85A2A`), dorado (`#F5B126`) y verde petróleo (`#064D4E`). Evitar las superficies verde pastel del diseño anterior.

# Uribia: revisión visual 2

11 propuestas generadas a partir de las referencias seleccionadas. Comparativo autónomo: `uribia-comparativo-v2.html` (22 imágenes incorporadas; no necesita red para mostrarlas).

- Faro Cabo F1: acercamiento solicitado de aproximadamente 50%.
- Pilón P1: encuadre ligeramente más amplio. La estatua no se distingue en la referencia; no se inventó una figura.
- Portada: plaza principal de Uribia.
- Centro Cultural: candidato urbano añadido por solicitud del propietario.
- La referencia rotulada previamente «Playa del Cabo» corresponde al sector de Playa Dorada junto al Pilón. No usarla para ilustrar la playa del poblado ni reutilizar sus coordenadas.

Los WebP finales de revisión son de 1200 × 800. `manifest.json` registra hashes y procedencia. Las versiones requieren aprobación visual exacta; no se han publicado ni sustituido activos del portal. Los permisos de las fuentes no se deducen de esa aprobación.

El constructor reproduce el HTML desde los WebP conservados; los PNG intermedios no son necesarios para reconstruir la revisión.
